💻 Spring University Application

This is a university management application built with Java and Spring Boot. It allows users to manage courses, students, and enrollments through a RESTful API.
The backend interacts with a PostgreSQL database, which is managed using PgAdmin and DBeaver. API endpoints are tested and documented using Postman.

The app demonstrates core concepts of Spring Boot such as dependency injection, data persistence with Spring Data JPA, and REST API design.

🔧 Tech Stack

- Spring Boot
- IntelliJ Ideea
- PgAdmin
- DBeaver
- Postman

## 🚀 How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/university-app.git
   cd university-app

2. Set up PostgreSQL database and configure connection properties in application.properties.
3. Run the application.
4. Use Postman to test the API endpoints.

📚 API Endpoints (Examples)

GET /courses — Retrieve all courses

POST /students — Add a new student

DELETE /enrollments/{id} — Delete an enrollment by ID

(Full API documentation available in Postman collection)
